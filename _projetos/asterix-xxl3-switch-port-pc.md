## Sobre o projeto

Este projeto reúne o trabalho de **Asterix & Obelix XXL 3 - The Crystal Menhir** para duas plataformas: a tradução para **Nintendo Switch** e o desenvolvimento de um **port para PC**.

A tradução para Nintendo Switch está disponível na **versão 1.0**. O port para PC permanece em desenvolvimento e poderá receber atualizações próprias.

## Instruções importantes

**Leia as instruções incluídas no arquivo de download antes de instalar ou utilizar os arquivos.** Verifique com atenção a plataforma, a versão do jogo e os procedimentos indicados. Não utilize arquivos destinados a uma plataforma em outra.
