Sobre o projeto

DESCRIÇÃO · BUILD 1.0

Está disponível a tradução de Asterix & Obelix XXL 2 para português brasileiro!

A Build 1.0 traz os textos do jogo traduzidos para PT-BR, com versões para PC e Nintendo Switch, permitindo jogar tanto no console quanto em emuladores compatíveis.

Plataformas disponíveis

  • PC: versão para computador.
  • Nintendo Switch: versão para console e emuladores.

Sobre esta versão

Esta build tem como foco a tradução dos textos. A tradução das texturas ainda não foi realizada e poderá chegar em uma atualização futura.

ATENÇÃO · NINTENDO SWITCH — Confira o Title ID da sua cópia antes de instalar. A compatibilidade depende da edição e da estrutura dos arquivos.
